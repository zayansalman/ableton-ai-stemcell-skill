# Security

Stemcell runs locally and sends no audio anywhere. The parts that touch your system are the CLI, the
`.als` editors in `studio/tools/` (they rewrite Ableton set files) and the optional MCP integrations.

## Reporting a problem

Please report security issues privately via
[GitHub's private vulnerability reporting](https://github.com/zayansalman/ableton-ai-stemcell-skill/security/advisories/new),
not as a public issue. You should hear back within a week.

## Supported versions

Only the latest release and `main` get fixes.
