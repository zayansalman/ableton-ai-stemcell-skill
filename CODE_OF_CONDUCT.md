# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, and assume good faith. Harassment, personal attacks and
discrimination are not welcome in issues, PRs or any other project space.

To report a problem, contact the maintainer ([@zayansalman](https://github.com/zayansalman)) privately through
[GitHub's private reporting](https://github.com/zayansalman/ableton-ai-stemcell-skill/security/advisories/new).
Reports are kept confidential.
